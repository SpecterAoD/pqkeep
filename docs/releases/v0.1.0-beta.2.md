**Second public beta of PQKeep** – post-quantum key generation and storage (ML-KEM, ML-DSA, AES-256-GCM, Argon2id), CLI and local REST API.

> ⚠️ **Beta, not audited, not FIPS 140 validated.** File formats and options may still change before 1.0. Do not use it for secrets you cannot afford to lose.

### What is new

- **Linux ARM64** release archive and **Debian packages** (`.deb`) for amd64 and arm64.
- **Signing and verifying** from the command line (`pqkeep sign` / `pqkeep verify`, detached `.pqsig` signatures).
- **Guided flows** for creating keys, signing and verifying; multi-selection in the menu; several sources per run.
- **File manager context menus** for Linux (Nemo, Nautilus, Dolphin, Thunar) and Windows, installed and removed with `pqkeep integrate`.
- **Unattended operation** with `--passphrase-file` and `--batch`.
- **New passphrases need at least 128 bits** (was 80); `--min-bits` raises the requirement. Existing files stay readable.

See [CHANGELOG.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.2/CHANGELOG.md) for the full list and [docs/SECURITY_REVIEW.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.2/docs/SECURITY_REVIEW.md) for the self-review.

### Verifying this release

The same three checks work for every `.tar.gz`, `.zip` and `.deb`; replace the file name as needed.

```
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify pqkeep-0.1.0-beta.2-amd64.deb --repo SpecterAoD/pqkeep
cosign verify-blob --bundle pqkeep-0.1.0-beta.2-amd64.deb.sigstore.json \
  --certificate-identity "https://github.com/SpecterAoD/pqkeep/.github/workflows/release.yml@refs/tags/v0.1.0-beta.2" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  pqkeep-0.1.0-beta.2-amd64.deb
```

The Windows binary is **not yet Authenticode-signed** (see the [code signing policy](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.2/CODE_SIGNING_POLICY.md)); Windows SmartScreen may warn on first start. It is covered by the attestation, Sigstore signature and checksum above.
