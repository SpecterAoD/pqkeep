**First public beta of PQKeep** – post-quantum key generation and storage (ML-KEM, ML-DSA, AES-256-GCM, Argon2id), CLI and local REST API.

> ⚠️ **Beta, not audited, not FIPS 140 validated.** File formats and options may still change before 1.0. Do not use it for secrets you cannot afford to lose.

See [CHANGELOG.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.1/CHANGELOG.md) for the full list and [docs/SECURITY_REVIEW.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.1/docs/SECURITY_REVIEW.md) for the self-review.

### Verifying this release

```
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify pqkeep-0.1.0-beta.1-x86_64-unknown-linux-gnu.tar.gz --repo SpecterAoD/pqkeep
cosign verify-blob --bundle pqkeep-0.1.0-beta.1-x86_64-unknown-linux-gnu.tar.gz.sigstore.json \
  --certificate-identity "https://github.com/SpecterAoD/pqkeep/.github/workflows/release.yml@refs/tags/v0.1.0-beta.1" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  pqkeep-0.1.0-beta.1-x86_64-unknown-linux-gnu.tar.gz
```

The Windows binary is **not yet Authenticode-signed** (see the [code signing policy](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.1/CODE_SIGNING_POLICY.md)); Windows SmartScreen may warn on first start. It is covered by the attestation, Sigstore signature and checksum above.
