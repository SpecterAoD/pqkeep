**Third public beta of PQKeep** – post-quantum key generation and storage (ML-KEM, ML-DSA, AES-256-GCM, Argon2id), CLI and local REST API.

> ⚠️ **Beta, not audited, not FIPS 140 validated.** File formats and options may still change before 1.0. Do not use it for secrets you cannot afford to lose.

### What is new

- **Optional second factor:** a factor file (`pqkeep factor`, `--factor-file`) in addition to the passphrase – also in the menu, the guided flows and the context menu.
- **Several recipients:** `--to` may be repeated (up to 64 public keys), optionally with your own passphrase (`--with-passphrase`); also in the menu and the context menu.
- **Backup checks:** `pqkeep check` verifies encrypted files completely without writing anything.
- **`--json`** for `check`, `inspect`, `verify`, `encrypt` and `decrypt` (one JSON object, stable exit codes – [docs/JSON.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.3/docs/JSON.md)).
- **Security fix for the REST API:** a web page could lock the local user out of `pqkeep serve`; browser requests are now rejected.
- **Fixes from hand testing:** free names keep the file extension (`report (2).txt.pqkf`), clearer passphrase window, robust `pqkeep integrate install`.

**Compatibility:** files and key files protected with a factor file or for several recipients use **format v2**, which beta.1 and beta.2 cannot open. Everything else is still written as v1 and stays readable by older betas.

See [CHANGELOG.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.3/CHANGELOG.md) for the full list and [docs/SECURITY_REVIEW.md](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.3/docs/SECURITY_REVIEW.md) for the self-review.

### Known limitations

- The new windows and context menu flows were **not hand-tested on Windows** – help is welcome in [#259](https://github.com/SpecterAoD/pqkeep/issues/259).
- ARM64 with 64 KiB pages is untested ([#163](https://github.com/SpecterAoD/pqkeep/issues/163)); Linux ARM64 with 4 KiB pages was checked on real hardware.

### Verifying this release

The same three checks work for every `.tar.gz`, `.zip` and `.deb`; replace the file name as needed.

```
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify pqkeep-0.1.0-beta.3-amd64.deb --repo SpecterAoD/pqkeep
cosign verify-blob --bundle pqkeep-0.1.0-beta.3-amd64.deb.sigstore.json \
  --certificate-identity "https://github.com/SpecterAoD/pqkeep/.github/workflows/release.yml@refs/tags/v0.1.0-beta.3" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  pqkeep-0.1.0-beta.3-amd64.deb
```

The Windows binary is **not yet Authenticode-signed** (see the [code signing policy](https://github.com/SpecterAoD/pqkeep/blob/v0.1.0-beta.3/CODE_SIGNING_POLICY.md)); Windows SmartScreen may warn on first start. It is covered by the attestation, Sigstore signature and checksum above.

**Dritte öffentliche Beta von PQKeep** – Erzeugung und Speicherung von Post-Quanten-Schlüsseln (ML-KEM, ML-DSA, AES-256-GCM, Argon2id), CLI und lokale REST-API.

> ⚠️ **Beta, nicht auditiert, nicht FIPS-140-validiert.** Dateiformate und Optionen können sich bis 1.0 ändern. Bitte nicht für Geheimnisse verwenden, deren Verlust nicht verkraftbar ist.

**Neu:** optionaler zweiter Faktor (Faktordatei, `pqkeep factor`, `--factor-file`, auch im Menü und Kontextmenü); mehrere Empfänger (`--to` mehrfach, bis 64, optional mit eigener Passphrase); `pqkeep check` prüft verschlüsselte Dateien vollständig; `--json` für `check`, `inspect`, `verify`, `encrypt` und `decrypt`; Sicherheitskorrektur der REST-API (eine Webseite konnte den lokalen Nutzer aussperren); Korrekturen aus dem Handtest (freie Namen behalten die Endung, klareres Passphrase-Fenster, robustes `integrate install`).

**Kompatibilität:** Dateien und Schlüsseldateien mit Faktordatei oder für mehrere Empfänger nutzen **Format v2**, das beta.1 und beta.2 nicht öffnen können. Alles andere wird weiter als v1 geschrieben.

**Grenzen:** Die neuen Fenster- und Kontextmenü-Abläufe sind unter **Windows nicht von Hand getestet** (Hilfe willkommen in #259); ARM64 mit 64-KiB-Seiten ist ungetestet (#163).

**Debian-Paket installieren:** `sudo apt install ./pqkeep-0.1.0-beta.3-amd64.deb` (bzw. `-arm64.deb`). Geprüft auf Debian 12/13 und Ubuntu 22.04/24.04/26.04; kein APT-Repository, Aktualisierung durch Installation des neueren Pakets.

**Prüfen:** wie oben (`sha256sum -c`, `gh attestation verify`, `cosign verify-blob`) – für `.tar.gz`, `.zip` und `.deb` gleich. Das Windows-Programm ist noch nicht Authenticode-signiert; SmartScreen kann beim ersten Start warnen. Es ist durch Attestation, Sigstore-Signatur und Prüfsumme abgesichert.
