# Sicherheitsrichtlinie / Security Policy

## Schwachstellen melden / Reporting a vulnerability

**DE:** Bitte melde Sicherheitslücken **nicht** als öffentliches Issue. Nutze die private Meldung über GitHub („Security“ > „Report a vulnerability“, Private Vulnerability Reporting). Wir bestätigen den Eingang in angemessener Zeit und stimmen die Veröffentlichung mit dir ab.

**EN:** Please do **not** report vulnerabilities as public issues. Use GitHub's private reporting ("Security" > "Report a vulnerability"). We will acknowledge receipt in a reasonable time and coordinate disclosure with you.

## Unterstützte Versionen / Supported versions

Solange das Projekt vor Version 1.0 steht, wird nur die jeweils neueste Version unterstützt. / Until 1.0, only the latest version is supported.

## Grenzen / Limitations

Das Projekt ist nicht extern auditiert, die Krypto-Bibliotheken sind nicht FIPS-140-validiert, und `zeroize` ist Best-Effort. Siehe `docs/SPEC.md`. / The project is not externally audited, the crypto libraries are not FIPS 140 validated, and `zeroize` is best effort. See `docs/SPEC.md`.
